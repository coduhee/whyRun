#iOS 자기소개 어플

Swift와 UIKit을 사용하여 개발한 iOS 자기소개 애플리케이션입니다.  
기본적인 UI 구성부터 화면 전환, 레이아웃 설계까지 iOS 앱 개발의 기초를 익히는 것을 목표로 제작한 팀 프로젝트입니다.

---

##  자기소개 어플 소개

이 앱은 사용자의 간단한 자기소개, 기술 스택, 각오 등을 한 화면 또는 여러 화면에 나누어 보여주는 iOS 애플리케이션입니다.  
스토리보드가 아닌 CodeBase 방식으로 UI를 구성하여 UIKit 구조에 대한 이해를 높이고자 했습니다.

---

##  사용 기술

- Language: Swift
- Framework: UIKit
- UI 방식: CodeBase (Storyboard 미사용)
- 개발 환경: Xcode
- 버전 관리: Git / GitHub

---

## ✨ 주요 기능

- 자기소개 정보 표시
- 기술 스택(사용 가능 언어/도구) 소개
- 화면 전환(NavigationController 기반)
- iOS UI 컴포넌트(Label, Button 등) 사용
